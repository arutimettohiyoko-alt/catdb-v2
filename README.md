# CATDB - にゃんこ図鑑

にゃんこ大戦争のキャラクターデータをステータス・特性で絞り込める図鑑アプリです。味方図鑑・敵図鑑の両方を、**Flask Blueprintで1つのアプリ（1つのポート）に統合**しています。

## ファイル構成

```
CATDB-main/
├── main.py                 ← 起動はこのファイルだけでOK
├── blueprints/
│   ├── ally.py              味方図鑑のロジック（旧 app.py）
│   └── enemy.py              敵図鑑のロジック（旧 app_enemy.py）
├── templates/
│   ├── zukan.html            味方図鑑の画面
│   └── zukan_enemy.html       敵図鑑の画面
├── ingest_data.py             味方データ収集スクリプト
├── ingest_data_enemy.py       敵データ収集スクリプト
├── nyanko_encyclopedia.json
└── nyanko_encyclopedia_enemy.json（要生成）
```

## セットアップ

```bash
pip install -r requirements.txt
```

## データの準備

```bash
python ingest_data.py         # 味方データ（同梱のJSONがあるので基本は不要）
python ingest_data_enemy.py   # 敵データ（同梱していないので必須）
```

### レアリティ絞り込みについて

レアリティ（基本／EX／レア／激レア／超激レア／伝説レア）で絞り込むには、`ingest_data.py` を一度再実行してデータを取得し直す必要があります（同梱の `nyanko_encyclopedia.json` にはレアリティ情報が含まれていません）。

ページ内のテキストから該当するレアリティ名を探すベストエフォートの実装のため、サイト側の表記が変わっている場合などに正しく取得できない可能性があります。

## 起動

```bash
python main.py
```

- 味方図鑑：`http://localhost:5000/`
- 敵図鑑　：`http://localhost:5000/enemy/`

**ポートは1つ（5000番）だけ**なので、ターミナルを1つ開いて `python main.py` を実行するだけで両方にアクセスできます。それぞれのページのヘッダーには、もう一方へ移動するリンクがあります。

## 機能（味方図鑑）

- キャラ名検索
- コラボキャラのみ / 除く の絞り込み
- レアリティでの絞り込み（要データ再取得）
- 対象（単体・範囲）での絞り込み
- 表示形態（最終形態 / 第1〜4形態）の切り替え
  - 絞り込み・特性表示は「表示中の形態」を基準に判定します。特性によっては特定の形態にしか存在しないものもあるため、見つからない場合は表示形態を変えてお試しください
- ステータス範囲での絞り込み（体力・攻撃力・DPS・射程・速度・コスト・再生産時間）
- 対応属性（赤い敵・黒い敵・エイリアンなど）での絞り込み
  - 「対 全ての敵（〇〇 除く）」表記も解析し、実際に対応する属性として反映
- 特殊効果（付与・特性）での絞り込み：
  超ダメージ／極ダメージ／打たれ強い／超打たれ強い／めっぽう強い／渾身の一撃／クリティカル／
  バリアブレイク／悪魔シールド貫通／波動／小波動／烈波／小烈波／爆波／ふっとばす／動きを止める／
  動きを遅くする／遠方攻撃／全方位攻撃／メタルキラー／ゾンビキラー／魂攻撃／召喚／超生命体特効／
  超獣特効／超賢者特効／魔女キラー／使徒キラー／連続攻撃／1回攻撃／攻撃力上昇／攻撃力低下／
  1度だけ生き残る／お金x2／対お城／メタル化／呪い
- 耐性・無効での絞り込み：
  波動無効／波動ストッパー／烈波無効／爆波無効／ふっとばす無効／動きを止める無効／
  動きを遅くする無効／攻撃力低下無効／ワープ無効／古代の呪い無効／毒撃無効／攻撃無効
  - 「特殊効果（付与・特性）」とは分離して判定しており、「〇〇無効」を持つキャラが誤って「〇〇を与えられる」扱いにならないようにしています
- 各項目でのソート（図鑑番号・名前・各ステータス、昇順・降順）
- ページネーション
- 該当キャラ名の一括コピー

## 敵図鑑（Enemy版）

### データの準備

```bash
python ingest_data_enemy.py
```

[にゃんこ大戦争DB 敵ステータス 全キャラ](https://battlecats-db.com/enemy/status_atr_all.html) を起点に、個別の敵ページを巡回してデータを取得します（`nyanko_encyclopedia_enemy.json` を生成）。

⚠️ **味方版と異なり、敵ページの実際のHTML構造を確認できない環境で実装したため、以下はベストエフォート実装です。** 再取得後、意図通りデータが取れているか（特に属性バッジの判定）ご確認ください。うまく取れていない項目があれば教えてください。
- 属性（白い敵・悪魔・超生命体など）：ページ本文からラベル文字列を検索して判定
- スターエイリアン：「エイリアン（スター）」という完全な表記でのみ判定（単なる「スター」だけでは誤検出するため）。エイリアンとは包含関係にあるため、「エイリアン」で絞り込んでもスターエイリアンが表示されます
- 対お城：ページ内に「お城」または「本体」という語があるかで判定

### 味方版との違い

- レアリティ・進化形態・コスト・再生産の概念が敵には無いため、それらの絞り込みはありません
- 属性は「対応属性（〇〇に強い）」ではなく、**その敵自身が持つ属性バッジ**（白い敵・悪魔・超生命体など）です
- **倍率スライダー**：一覧の各行に倍率（%）を設定するスライダー・数値入力欄があります。100%を基準に、体力・攻撃力・DPSがその倍率分だけ増加した値をリアルタイムに再計算して表示します（ステージによって強化されている敵の数値を確認する用途を想定しています）。スライダーの操作はブラウザ内で完結し、絞り込み条件には影響しません
- 特性・耐性のキーワードは敵専用のリストに変更しています（渾身の一撃・波動・地中移動・バリア・悪魔シールドなど）
- 「該当キャラ名を一括コピー」機能は敵版にもそのまま搭載しています
